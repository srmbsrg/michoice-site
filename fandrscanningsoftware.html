Key Features

OCR Data Extraction

Optical character recognition reads application fields directly from scanned images — eliminating manual data entry for every field on every form.

Batch Scanning

Process multiple paper applications in a single scan session. Suitable for high-volume intake periods at the start of school year.

Exception Flagging

Fields that OCR cannot read with sufficient confidence are flagged for manual review — staff only intervene where genuinely needed, not on every form.

Digital Image Archive

The original scanned image is retained alongside the extracted data — providing a permanent digital copy of the paper application for audit purposes.

FAR-Apps Integration

Extracted data flows directly into FAR-Apps. The scanned application enters the same determination workflow as a digitally submitted application — processed identically.

No Manual Re-Entry

The entire data capture step is automated. Staff no longer keyboard-enter income figures, household sizes, and student information from paper forms.

Error Reduction

OCR-extracted data is validated against field rules automatically. Many data entry errors that occur in manual keying never enter the system at all.

Seamless with Online Portal

Works alongside the Online F&R Application Portal — paper and online intake both feed the same FAR-Apps workflow. Districts don't need separate processes for each channel.

Why Paper Applications Still Matter

Every district wants to maximize online F&R application submissions — and the Online F&R Application Portal makes that possible. But paper applications aren't going away entirely. Households without reliable internet access, families more comfortable with paper, and students who receive forms at school rather than online all contribute to a continuing flow of paper applications in most districts.

The F&R Scanning Software ensures that paper applications don't create a two-tier process — one digital and efficient, one manual and labor-intensive. Both channels produce the same result: a clean digital record in FAR-Apps, ready for determination.

How OCR Works in Practice

The MiChoice form is designed for OCR readability — structured fields, clear layout, and formatting that the software is trained to recognize. When a batch of paper applications is scanned, the software reads each field systematically: student names, household income figures, household size, benefit certifications, and all other required NSLP data elements. Fields it reads with high confidence pass directly to FAR-Apps. Fields it cannot read clearly are flagged — presented to a staff member for quick review and correction before the application is submitted to FAR-Apps.

The Audit Archive

Beyond data extraction, the scanning software creates a searchable archive of application images. Every scanned application is stored as a retrievable digital file — linked to the corresponding FAR-Apps record by student and household. When a state or federal audit requires producing the original application, the digital image is found instantly. The physical paper backlog that NSLP compliance once required maintaining can be dramatically reduced.
